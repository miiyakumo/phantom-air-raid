# 战斗循环重构：第一轮

基于 main `32c882409a83d9287abb07424f44cbd71a5414de`。目标是先恢复可靠的“躲避—攻击—获得资源—成长—下一章”循环；不是宣布五章难度已经调平。

## 当前规则

- 自动选敌、自动射击；不需要按 J，静止不会停火。主弹保持完整伤害，多弹丸升级实际增加侧弹。近距奖励不要求静止。
- 基础升级统一提高攻击、射速和生命；击杀姿态不再改变成长方向。三选一提供明确的正向强化，候选绑定到当次升级，暂缓选择不能重抽。
- 冲刺固定 4 秒冷却、160 像素位移，提供短暂无敌并清除经过的敌弹。冷却与站位无关。钩爪、金苹果为可选消耗品。
- 敌人采用接近、预警、沿锁定方向攻击、收招的流程；收招受到额外伤害。保留六种敌人、五章 Boss、精英方向护盾与敌人互相伤害。
- 爆炸和音波对每个目标每次施放最多结算一次完整伤害，不再把每帧伤害送入受击无敌。敌人互伤按实际范围判定，不要求玩家站在两敌之间。
- 经验与治疗可靠到账；掉落自动吸取，核心可正常拾取并提供 6 秒增伤。常规掉落不再限时消失，满掉落池时直接结算。
- Boss 半血进入第二阶段，不因玩家远离而回血。章节在边缘与中央等速推进；波次轮换，不提前把尚未击败的 Boss 当普通敌人生成。
- 击败 Boss 后清除残余敌人与弹幕、回收掉落、回复部分生命、刷新冲刺，提供 5 秒安全休整，再引入降级后的旧 Boss。最后一个 Boss 击败后自动胜利结算。
- 暂停冻结战斗计时、物理、场景定时器与补间动画。重新开始清理输入监听器。本地存储被阻止或数据损坏不再影响结算。

## 本轮主动移除的实验机制

热量停火、静止惩罚、姿态升级、限时遗珠兑奖、连击兑现按键、断链站位验证、携带核心灼烧、按特定键才产生擦弹收益、屏幕外弹幕折返。原代码留在父提交中，不以未调用的大段死代码保留在战斗场景里。

这是简化后的战斗基线，不是所有实验机制的最终否定。后续逐个引回时，应各自有可见反馈、独立玩法价值与测试，不应重新成为基本攻击或基础奖励的前置条件。
